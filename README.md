# WXT + React

This template should help get you started developing with React in WXT.

https://wxt.dev/

# Current Node version

- Now using node v20.20.2 (npm v10.8.2) 

# Installation

- npm install pnpm
- pnpm install

# Run dev

- pnpm dev

# Build firefox

- pnpm build:firefox

# Build chrome

- npm run build
- pnpm build

# Build chrome (using obfuscation technique)

- npm run build:protected
